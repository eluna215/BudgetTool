# Payweek

A payday-to-payday budget: what's due, what's spent and what's left between paydays, with a warning before you come up short.

- `index.html`: home page
- `app.html`: the budget tool
- `site.css`, `icon.png`: shared look and icon

Everything runs in the browser. Each visitor's data is saved in their own browser, and **Export** / **Import** move it between devices.

These files are built from the main project (`src/payweek.html` → `npm run site`). Don't edit `app.html` here by hand.
